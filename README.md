# 🩺 Diabetes Prediction System

> AI-powered Diabetes Prediction web app using Machine Learning to predict diabetes risk with high accuracy.

## 🎯 Problem Statement

Early detection of diabetes helps reduce severe health complications and improves preventive healthcare.
This system predicts diabetes risk using important medical parameters.

## ⚡ Quick Demo

Input: Age=45, BMI=31.2, HbA1c=6.8, Blood Glucose=155
Output: ⚠️ HIGH RISK (Probability: 91%)

## 🛠️ Tech Stack

* Python, Pandas, NumPy
* Scikit-learn, XGBoost, Random Forest
* Flask (Web Application)
* HTML, CSS, Bootstrap
* Dataset: Diabetes Healthcare Dataset

## 📊 Model Performance

| Metric          | Score                              |
| --------------- | ---------------------------------- |
| Accuracy        | 90–95%                             |
| Algorithms      | XGBoost / Random Forest            |
| Features Used   | 4 (Age, BMI, HbA1c, Blood Glucose) |
| Prediction Type | Diabetes Risk Classification       |
